Mr. Usage › SE Ranking

Check what you have left at SE Ranking

Mr. Usage reads SE Ranking's documented usage endpoint with your own key and keeps a card with data API units left of the subscription's total, with the subscription expiry as the renewal date, refreshed on its own.

Install Mr. Usage GitHub repository

What the SE Ranking card shows

Data API units left of the subscription's total, with the subscription expiry as the renewal date. A yellow "Low" badge appears under 20% left and a red "Nearly out" badge under 5%, with a line of today's readings underneath.

Counts Data API units for the subscription; the renewal date is its expiration date.

What Mr. Usage reads

Call`GET https://api.seranking.com/v1/account/subscription?output=json`
Authentication`Authorization: Token <key>` header.
Verified againsthttps://seranking.com/api/data/account-system/
Anything else contactedNothing. The host is on a per-provider allowlist checked before every request, redirects are off, and the connection is TLS 1.2 or newer.

The app shows you this exact address before you save a key, and docs/SOURCES.md records where each fact came from and when it was read.

Questions

Does checking my SE Ranking usage cost credits?

the docs state 0 credits.

Where does my SE Ranking API key go?

Into your operating system's credential store, under the service name mr-usage: Keychain on macOS, Credential Manager on Windows, the Secret Service on Linux. The app reads it at the moment it calls the vendor, wraps it in a zeroizing type, and drops it. It is never written to a file of the app's own and never sent back to the window.

How often is the card refreshed?

Every 5 minutes by default. Settings lets you pick anything from 1 minute to 24 hours, and changing the interval takes effect from the last poll. There is also a Refresh button on each card, limited to once a minute.
