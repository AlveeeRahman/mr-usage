Mr. Usage › SerpApi

Check how many SerpApi searches you have left

Mr. Usage reads SerpApi's Account API with your key and shows the searches left this month, the renewal date and this hour's usage against your hourly limit.

Install Mr. Usage GitHub repository

What the SerpApi card shows

Searches left this month out of the plan, the renewal date, extra credits, and this hour's searches against the hourly rate limit. A yellow "Low" badge appears under 20% left and a red "Nearly out" badge under 5%, with a line of today's readings underneath.

The response echoes the key and the account email. The parser never reads those fields, and a test fails the build if a struct ever names them.

The app shows you this exact address before you save a key, and docs/SOURCES.md records where each fact came from and when it was read.

Questions

Does checking my SerpApi usage cost credits?

SerpApi documents the Account API as free of charge and not counted toward the monthly quota.

Where does my SerpApi API key go?

Into your operating system's credential store, under the service name mr-usage: Keychain on macOS, Credential Manager on Windows, the Secret Service on Linux. The app reads it at the moment it calls the vendor, wraps it in a zeroizing type, and drops it. It is never written to a file of the app's own and never sent back to the window.

How often is the card refreshed?

Every 5 minutes by default. Settings lets you pick anything from 1 minute to 24 hours, and changing the interval takes effect from the last poll. There is also a Refresh button on each card, limited to once a minute.
