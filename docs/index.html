Mr. Usage

A desktop API credit monitor. Mr. Usage shows, in one window, how many Firecrawl, SerpApi and Elicit credits you have left, when your plan renews, and how the number moved today. You paste each API key once. It goes into your operating system's own credential store and never comes back to the window.

GitHub repository Latest release

What it does

  • Polls each vendor's documented usage endpoint and shows remaining credits out of your plan, the renewal or period-end date, and a line of today's readings.
  • Marks a provider Low under 20% and Nearly out under 5%, with a word next to the colour so the state never depends on colour alone.
  • Keeps usage history in memory only. It is wiped at local midnight, when you press Wipe history now, and when the app quits.
ProviderEndpoint the app callsNotes
FirecrawlGET https://api.firecrawl.dev/v2/team/credit-usageChecked every 30 minutes at most, because Firecrawl does not document whether this call costs a credit.
SerpApiGET https://serpapi.com/account.jsonFree, and does not count against your searches.
ElicitGET https://elicit.com/api/v2/usageReported as a percentage of your plan. Needs a Pro plan or above.

Install

Download the installer for your platform from GitHub Releases and check it against SHA256SUMS.txt from the same release: a .dmg for macOS (Apple silicon or Intel), a -setup.exe or .msi for Windows, and a .deb, .rpm or AppImage for Linux. The builds are not code-signed, and the README explains what macOS and Windows will say and how to open the app anyway.

# or build it yourself
git clone https://github.com/AlveeeRahman/mr-usage.git && cd mr-usage
cargo install tauri-cli --version 2.12.3 --locked
cargo tauri build

Where your keys live

macOS Keychain, Windows Credential Manager, or the Secret Service on Linux (GNOME Keyring, KWallet, KeePassXC), under the service name mr-usage. The app reads a key at the moment it calls the vendor, wraps it in a zeroizing type, and drops it. There is no server, no account, no analytics and no update check. The only network traffic is the usage call to each vendor you added a key for, over TLS 1.2 or newer to a fixed host list.

The full security design is in the threat model, every external fact is sourced in SOURCES.md, and an independent review is in REVIEW.md.

Tested on every change

CI runs the Rust tests on macOS, Windows and Linux, a key-leak test against a real Secret Service, an end-to-end WebDriver run of the real app, and cargo deny, cargo audit and npm audit. A second workflow builds the real installers and checks that each one installs, starts, stops cleanly three ways and uninstalls without leaving files behind.
