Mr. Usage

A desktop API credit monitor. Mr. Usage shows, in one window, how many credits you have left at Firecrawl, SerpApi, Elicit, Context7, Tavily, OpenRouter, Apify, Hunter and Runway, when each plan renews, and how the numbers moved today. You paste each API key once. It goes into your operating system's own credential store and never comes back to the window.

GitHub repository Latest release

What it does

Each provider has its own page with the exact endpoint the app reads and whether the vendor says the call is free: Firecrawl, SerpApi, Elicit, Context7, Tavily, OpenRouter, Apify, Hunter, Runway.

  • Polls each vendor's documented usage endpoint and shows remaining credits out of your plan, the renewal or period-end date, and a line of today's readings.
  • Marks a provider Low under 20% and Nearly out under 5%, with a word next to the colour so the state never depends on colour alone.
  • Keeps usage history in memory only. It is wiped at local midnight, when you press Wipe history now, and when the app quits.

Install

macOS or Linux, in a terminal:

curl -fsSL https://raw.githubusercontent.com/AlveeeRahman/mr-usage/main/installers/install.sh | sh

Windows, in PowerShell:

irm https://raw.githubusercontent.com/AlveeeRahman/mr-usage/main/installers/install.ps1 | iex

The command picks the right package for your machine, checks it against the release's checksum list, installs it and clears the "downloaded from the internet" flag, so the app opens without a detour through security settings. To install by hand instead, download from GitHub Releases; the README lists which file is which and what macOS and Windows will say about an unsigned app.

Where your keys live

macOS Keychain, Windows Credential Manager, or the Secret Service on Linux (GNOME Keyring, KWallet, KeePassXC), under the service name mr-usage. The app reads a key at the moment it calls the vendor, wraps it in a zeroizing type, and drops it. There is no server, no account, no analytics and no update check. The only network traffic is the usage call to each vendor you added a key for, over TLS 1.2 or newer to a fixed host list.

The full security design is in the threat model and every external fact is sourced in SOURCES.md.

Questions

How do I check my API credits?

Most vendors publish a usage endpoint that returns your remaining credits when called with your own key. Mr. Usage calls that endpoint for each provider you add, every 5 minutes by default, and shows the answer on a card. The endpoint for each vendor is listed on its page below.

How do I check my OpenRouter balance?

Add your OpenRouter key to Mr. Usage. It reads the key's own record and shows the dollars left on its credit limit, the workspace budget where the key has no limit, and this month's spend.

Does checking usage cost credits?

SerpApi, Context7 and Hunter document their usage calls as free. Firecrawl's open-source server shows its call bills nothing. Tavily lists only search, extract, map, crawl and research as billable. Elicit, OpenRouter, Apify and Runway do not say, and the card for each says so.

Where are my API keys stored?

In your operating system's credential store under the service name mr-usage: Keychain on macOS, Credential Manager on Windows, the Secret Service on Linux. The app reads a key at the moment it calls the vendor and drops it afterwards. It never writes a key to a file of its own and never sends one back to the window.

Is Mr. Usage free?

Yes. It is open source under MIT or Apache-2.0, has no account and no paid tier, and talks to nothing but the usage endpoint of each vendor you gave it a key for.

Which operating systems does it run on?

macOS (Apple silicon and Intel), Windows, and Linux as a .deb, .rpm or AppImage. One install command per platform is on this page.

Uninstall

Run the same command with --uninstall (macOS, Linux) or -Uninstall (Windows). It removes the keys from your credential store, then the app, then its settings.
